# p967-c7-rtt — журнал SEGGER RTT цели по MQTT (С7)

Ветка `feat/rtt-mqtt` от `origin/feat/s3-idf61`. PR не открыт (по заданию).

## Что сделано
- `main/rtt_parse.[ch]` — чистая часть без ESP-IDF и SWD: поиск подписи `SEGGER RTT` (границы по 4 байта),
  разбор блока и дескриптора up 0 (отказы: мало данных / нет подписи / число буферов вне 1..16 / размер 0 или
  смещения за кольцом), доступное в кольце (пусто `wr==rd`, полное `size-1`), план чтения с обёрткой через конец и
  пределом за опрос, сборщик строк (склейка кусков, CRLF, переполнение, flush по простою).
- `tests/host/test_rtt_parse.c` + `tests/host/run.sh` — хост-тест. Сначала запущен против заглушек: **красный, 24 провала**;
  с реализацией — `OK`.
- `main/rtt_mqtt.[ch]` — задача: по SWD (`swd_read_memory`/`swd_write_word` из `swd_host`) ищет блок в окне
  кусками по 1 КБ с перекрытием, раз в N мс читает WrOff/RdOff, забирает up 0, двигает RdOff, строки шлёт в `rtt/<mac>`
  (mac Wi-Fi STA, нижний регистр). Потеря чтения или нелепые смещения (цель перезапущена) — повторный поиск блока.
- Настройки (Kconfig — запасные, NVS namespace `rtt` переопределяет): `en` (по умолчанию ВЫКЛ), `win_lo`/`win_hi`
  (по умолчанию 0x20000000..0x20040000, RAM nRF52840), `poll_ms` (100), `uri`, `user`, `pass`. Секретов в git нет:
  URI/логин/пароль в Kconfig пустые, пустой URI — модуль не стартует.
- `main/idf_component.yml`: `espressif/mqtt` (в IDF 6.1 вынесен из ядра); `dependencies.lock` обновлён.
- `components/DAP/source/swd_host.c`: добавлено определение `swd_set_target_reset` (объявлена в `target_family.h`,
  нигде не определена — раньше `swd_host` не линковался, теперь его зовёт RTT; через `PIN_nRESET_OUT`, активный 0).
